# Boson Science licensing policy

Boson Science projects may use a range of open-source licenses. Each project's
repository identifies the license that applies to its software and assets.
Choose terms that fit the project and review them before public release.

## Repository requirements

Every public project must:

1. include a complete `LICENSE` file;
2. identify the applicable license with its exact SPDX expression in package
   and release metadata when those formats support it;
3. mark copied or vendored third-party material with its origin and license;
4. review dependency licenses for compatibility before release; and
5. state any exceptions or separately licensed assets explicitly.

Code is not open source merely because it is visible. Until a repository has an
explicit license, others have no general permission to copy, modify, or
redistribute it.

Game concepts, worlds, characters, and other creative content remain Boson
Science intellectual property unless a project explicitly states otherwise.
Software methods and tools developed for games may be released under an
open-source license selected for the relevant project. Software licenses do not
automatically grant rights to game content, brands, or other creative assets.

Changing a released project's license requires organization-owner approval and
a documented rights review. Contributions already accepted from other authors
may prevent relicensing without their permission.
