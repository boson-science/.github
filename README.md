# Boson Science organization defaults

This repository defines the public profile and default community health files
for the [Boson Science](https://github.com/boson-science) GitHub organization.

Repositories may override these defaults when a project has more specific
requirements. Project-specific files take precedence over the files here.

## Contents

- `profile/README.md` — public organization profile
- `assets/boson-science-mark.png` — transparent high-resolution brand mark
- `assets/boson-science-avatar-512.png` — upload-ready GitHub avatar
- `CONTRIBUTING.md` — default contribution process
- `CODE_OF_CONDUCT.md` — community conduct expectations
- `SECURITY.md` — responsible vulnerability reporting guidance
- `SUPPORT.md` — support boundaries
- `LICENSE_POLICY.md` — project licensing policy
- `.github/ISSUE_TEMPLATE/` — default issue forms
- `.github/pull_request_template.md` — default pull request checklist
