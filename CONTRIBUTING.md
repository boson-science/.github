# Sharing ideas about Boson Science projects

We welcome ideas and feedback through issues on repositories that have issues
enabled. Boson Science is not recruiting or seeking outside code contributions
at this time. Some community-maintained projects may have their own contribution
process; check the repository's guidance first.

## Before opening an issue

1. Read the repository README and existing documentation.
2. Search open and closed issues for an existing report or proposal.
3. Confirm that the topic belongs to this repository.
4. Do not report security vulnerabilities in a public issue; follow
   `SECURITY.md` instead.

## Conduct

Participation is governed by `CODE_OF_CONDUCT.md`.
