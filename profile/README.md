# Boson Science

Boson Science researches, builds, and publishes open-source software.

## How we work

Projects begin in private incubation so that their purpose, security model,
documentation, and release boundary can be established deliberately. When a
project is ready for public use and collaboration, we publish its source,
history, license, and contribution guidance.

Boson Science software is released under one of two licenses:

- **MIT** for components intended for broad reuse and integration.
- **GNU AGPL v3.0** for networked systems where users should receive the source
  for the version of the software they interact with, including deployed
  modifications.

Each repository identifies its license explicitly. There is no organization-wide
assumption that unlabeled code is open source.

## Projects

We are preparing our first public releases. Published projects will appear on
this organization page when they meet the Boson Science release baseline.

## Contributing

Public projects welcome well-scoped issues and pull requests. Please read the
repository's README, contribution guide, and code of conduct before proposing a
change. Project-specific guidance takes precedence over organization defaults.

## Security

Please do not disclose suspected vulnerabilities in public issues. Use the
affected repository's **Security** tab to submit a private vulnerability report
or follow the private reporting instructions in its `SECURITY.md`.
